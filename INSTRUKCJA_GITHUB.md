# 🚀 Jak wrzucić projekt na GitHub - Krok po kroku

## Sposób 1: Przez terminal (SZYBKI - 2 minuty)

### Krok 1: Utwórz repozytorium na GitHub
1. Otwórz: https://github.com/new
2. Wypełnij:
   - **Repository name**: `antik-holz-order-form`
   - **Description**: `Formularz zamówień dla ANTIK-HOLZ - stare deski rustykalne ze stodoły`
   - Wybierz **Public** lub **Private**
   - **NIE zaznaczaj** żadnych checkboxów!
3. Kliknij **Create repository**

### Krok 2: Uruchom te komendy w Git Bash
Otwórz Git Bash w folderze projektu i wykonaj:

```bash
cd "C:/Users/biuro/antik-holz-order-form"

# Zamień YOUR_USERNAME na swoją nazwę użytkownika GitHub
git remote add origin https://github.com/YOUR_USERNAME/antik-holz-order-form.git

git branch -M main

git push -u origin main
```

**GOTOWE!** 🎉

---

## Sposób 2: GitHub Desktop (NAJŁATWIEJSZY - klik klik)

### Krok 1: Zainstaluj GitHub Desktop
Pobierz z: https://desktop.github.com/

### Krok 2: Zaloguj się do GitHub
1. Uruchom GitHub Desktop
2. File → Options → Accounts → Sign in

### Krok 3: Dodaj projekt
1. File → Add Local Repository
2. Wybierz folder: `C:\Users\biuro\antik-holz-order-form`
3. Kliknij **Add Repository**

### Krok 4: Opublikuj
1. Kliknij **Publish repository** (prawy górny róg)
2. Nazwa: `antik-holz-order-form`
3. Opis: `Formularz zamówień dla ANTIK-HOLZ`
4. Odznacz "Keep this code private" jeśli chcesz publiczne repo
5. Kliknij **Publish Repository**

**GOTOWE!** 🎉
